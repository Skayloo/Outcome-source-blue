**веб** — полная поверхность, **приложение для iOS** закрывает всё, что делаешь каждый день.
Там, где что-то умеет только один из них, это сказано отдельно.

Скриншоты сняты на живом инстансе от владельца пространства; обычный участник видит те же

## Вход

<p align="center"><img src="images/01-login.png" alt="Экран входа" width="820"></p>

Вход по почте с паролем — или через того провайдера, которого настроил хозяин инстанса
(кнопки под формой появляются, только когда провайдер действительно подключён).

**Создание аккаунта.** Первый аккаунт на чистом инстансе становится **владельцем**
пространства. Дальше форма регистрации зависит от того, как инстанс настроен:

| Настройка | Что видно |
| --- | --- |
| Регистрация открыта | Форма работает как на скриншоте |
| Только по приглашениям | Форма дополнительно просит код приглашения |
| Подтверждение почты | После формы на адрес уходит код из 6 цифр; аккаунт появляется, только когда код введён |
| Регистрация закрыта | Регистрации нет вовсе — аккаунт должны завести вам |

**Отдельно про вход через провайдера.** У аккаунта, созданного через провайдера, своего пароля
нет, а приложение для iOS умеет входить только по почте с паролем. Outcome попросит придумать
пароль при первом входе в вебе — чтобы тот же аккаунт работал и на телефоне.

## Как устроен веб-клиент

<p align="center"><img src="images/02-chat.png" alt="Канал сервера" width="900"></p>

Четыре колонки слева направо:

1. **Рейл серверов** — сверху личные сообщения, потом по иконке на каждый сервер, где вы
   состоите, потом *Добавить сервер*, *Обзор серверов* и *Разработчику*. Зелёная точка на
   иконке сервера значит, что кто-то сидит в его голосовом канале.
2. **Список** — каналы, когда выбран сервер; диалоги, когда выбраны личные сообщения.
3. **Переписка**.
4. **Участники** — по умолчанию скрыты, показывает иконка с людьми в шапке.

**Список тянется за край.** Потяните его правую границу, как в десктопных мессенджерах;
двойной клик по границе возвращает ширину по умолчанию. Ширина запоминается в браузере и
ограничена диапазоном 240–560 px, чтобы переписка за неё не расплачивалась.

<p align="center"><img src="images/03-dm-list.png" alt="Расширенный список диалогов" width="900"></p>

**Перемещение без мыши.** `⌘K` / `Ctrl-K` — или поле *Search* над списком — открывает командную
палитру: набираешь несколько букв канала, сервера, человека или действия, стрелками до нужного,
Enter.

<p align="center"><img src="images/18-command-palette.png" alt="Командная палитра" width="900"></p>

## Сообщения

Пишете в поле внизу. **Enter** отправляет, **Shift+Enter** переносит строку. `@` начинает
упоминание и подсказывает тех, кто видит этот канал. Ссылки становятся ссылками, ссылка на
картинку показывает картинку.

Наведите курсор на сообщение — над ним появится панель:

<p align="center"><img src="images/20-message-actions.png" alt="Действия над сообщением" width="900"></p>

| | |
| --- | --- |
| 🙂 | Реакция — выбрать эмодзи; реакции считаются под сообщением |
| ↩ | Ответ — цитата висит над полем ввода, пока печатаете, а потом по клику перепрыгивает к оригиналу |
| → | Переслать — в любой канал или диалог, в том числе на другом сервере |
| ⚑ | Пожаловаться — см. [Жалобы](#жалобы-и-работа-с-ними). На своих сообщениях кнопки нет |
| 📌 | Закрепить / открепить |
| ✏ | Изменить — только свои; после правки сообщение помечается как изменённое |
| 🗑 | Удалить — свои; в личном чате любой из двоих может удалить что угодно, и строка стирается у обоих |

**Закреплённые сообщения** живут за иконкой булавки в шапке:

<p align="center"><img src="images/27-pinned.png" alt="Закреплённые сообщения" width="900"></p>

**Поиск.** Поле в шапке ищет по текущей переписке; в результатах видно автора, канал и время, а
клик перепрыгивает к сообщению на его месте в истории.

<p align="center"><img src="images/19-chat-search.png" alt="Результаты поиска" width="900"></p>

**Голосовые сообщения.** Микрофон справа от поля ввода записывает; та же кнопка отправляет,
корзина отменяет. Играются прямо в переписке — с волной и переключателем скорости.

## Картинки и файлы

Скрепка слева от поля ввода спрашивает, *как* отправить, и от ответа зависит, что будет
храниться:

<p align="center"><img src="images/21-attach-menu.png" alt="Меню вложения" width="900"></p>

- **Фото** — картинка пережимается под коробку 1600 px, и **эта копия сохраняется вместо
  оригинала**. Так задумано, и дверь захлопывается за собой: исходный файл никуда не пишется.
  1600 px больше, чем показывает любой здешний экран, а хранить оба варианта — это бакет,
  который растёт в тридцать раз быстрее самой переписки. Картинку, которая и так меньше
  коробки, сохраняют как есть.
- **Файл (исходное качество)** — байты сохраняются нетронутыми, а в сообщении появляется строка
  файла с кнопкой скачивания. Так и надо отправлять фотографию, которая кому-то нужна в полном
  разрешении.

Файлы можно и просто перетащить в окно или вставить из буфера.

Вложения копятся в лотке над полем ввода, у каждого своё кольцо прогресса, и уходят они только
вместе с сообщением. Принимается файл до **100 МБ**.

<p align="center"><img src="images/24-upload-pending.png" alt="Вложения перед отправкой" width="900"></p>

Несколько картинок в одном сообщении складываются в альбом: до десяти, разложенных так, чтобы
заполнить пузырь и ничего не обрезать в квадрат.

<p align="center"><img src="images/22-album.png" alt="Альбом из пяти фотографий" width="900"></p>

Клик по любой открывает просмотрщик: стрелки на экране или ←/→ листают альбом, счётчик говорит,
где вы находитесь, а **Open original** открывает сохранённую копию в новой вкладке.

<p align="center"><img src="images/23-lightbox.png" alt="Просмотрщик картинок" width="900"></p>

## Личные чаты, друзья и звонки

Иконка с облачком в самом верху рейла переключает всю левую часть на диалоги.

<p align="center"><img src="images/04-dm.png" alt="Личная переписка" width="900"></p>

**Друзья** — первая строка этого списка: три вкладки — ваши друзья, входящие заявки и поиск,
который находит людей по имени пользователя или почте. Заявки приходят сразу; принятая заявка
открывает переписку.

<p align="center"><img src="images/17-friends.png" alt="Друзья" width="900"></p>

**Личные сообщения приватные, но не тайные.** Они лежат на том сервере, куда вы вошли, и тот, кто
им управляет, может прочитать базу, в которой они хранятся. Входите туда, кому доверяете.

**Звонки.** Трубка в шапке диалога звонит собеседнику: у него на весь экран появляется входящий
с рингтоном и кнопками принять/отклонить, а дальше вы оба оказываетесь в закрытой голосовой
комнате. Звонок тому, кто не в сети, встаёт на паузу — он получит его, как только откроет
приложение.

## Голос и видео

Клик по голосовому каналу — и вы в нём. Сцена занимает область переписки, а маленькая панель
внизу сайдбара следует за вами по другим каналам.

<p align="center"><img src="images/25-voice.png" alt="Голосовой канал" width="900"></p>

| Кнопка | |
| --- | --- |
| **Mic** | Заглушить себя. Пока вы действительно говорите, вокруг вашей плитки горит кольцо |
| **Sound** | Оглохнуть — глушит всех остальных и заодно вас |
| **Video** | Камера |
| **Screen** | Демонстрация экрана или отдельного окна |
| **Guest link** | Создаёт ссылку, по которой в этот голосовой канал попадёт человек **без аккаунта**, и кладёт её в буфер обмена |
| **Disconnect** | Выйти |

Правый клик по участнику даёт отдельный ползунок громкости для него — помогает задолго до того,
как начнёшь винить чьи-то настройки.

**Горячие клавиши в канале:** `Ctrl/⌘+Shift+M` — микрофон, `Ctrl/⌘+Shift+D` — оглохнуть,
`Ctrl/⌘+Shift+V` — камера. Push-to-talk выключен, пока не назначишь клавишу в
*Настройки → Voice & Audio*; после этого удержание клавиши открывает микрофон, а отпускание
закрывает — даже когда окно не в фокусе.

**Если слышно комнату вокруг вас**, откройте *Настройки → Voice & Audio*: там живут шумодав,
чувствительность микрофона и выбор устройств ввода и вывода. Гости, пришедшие по ссылке,
получают ту же обработку, но их браузер докачивает её уже на входе — первые пару секунд гость
может звучать шумнее остальных.

<p align="center"><img src="images/06-voice-settings.png" alt="Настройки звука" width="900"></p>

> Микрофону, камере и демонстрации экрана нужен защищённый контекст. По простому `http://` на
> что-либо кроме `localhost` браузер просто откажет в доступе, и звонок соединится с тишиной.

## Серверы и каналы

Сервер — это пространство со своими каналами, участниками и ролями. Один инстанс держит их
много, рейл между ними переключает.

**Как попасть на сервер.** У *Добавить сервер* две вкладки: **Create** заводит новый вместе с
`#general` и голосовым *General*, **Join** принимает код приглашения.

<p align="center"><img src="images/28-create-server.png" alt="Создать или найти сервер" width="900"></p>

*Обзор серверов* показывает те, что владельцы пометили как публичные, — туда пускают без
приглашения.

<p align="center"><img src="images/16-explore.png" alt="Обзор публичных серверов" width="900"></p>

**Как управлять своим.** Клик по названию сервера над списком каналов открывает меню: позвать
людей, создать канал, открыть **Настройки сервера**, удалить сервер. Что именно предложит меню,
зависит от того, что вам позволено.

<p align="center"><img src="images/08-server-settings.png" alt="Настройки сервера" width="900"></p>

| Вкладка | |
| --- | --- |
| **Overview** | Имя, иконка, публичный или закрытый, удаление |
| **Channels** | Создать, переименовать, переставить, заархивировать; текстовый или голосовой; тема канала и медленный режим |
| **Members** | Кто здесь и какая у него роль **на этом сервере** |
| **Invites** | Создать коды, задать срок или лимит использований, отозвать |
| **Reports** | Жалобы на сообщения **этого** сервера — вкладка видна только тем, кто может по ним что-то сделать |

<p align="center">
  <img src="images/14-server-members.png" alt="Участники сервера" width="440">
  <img src="images/15-server-invites.png" alt="Приглашения сервера" width="440">
</p>

**Роли двухслойные, и разница важна.** Роль в *пространстве* (её выдают в админ-консоли)
действует везде; роль *внутри одного сервера* назначается на вкладке Members этого сервера и
действует только там. Быть администратором своего сервера не значит быть администратором
чужого. Владелец сервера — администратор в нём, какая бы роль ни стояла у него в пространстве.

Список участников справа от канала показывает, кто в сети, и с какой ролью на сервере:

<p align="center"><img src="images/26-members.png" alt="Список участников" width="900"></p>

## Жалобы и работа с ними

**Со стороны участника.** Наводите на сообщение → флажок. Outcome попросит подтвердить и даст
дописать строку о том, что с сообщением не так. Текст сообщения **снимается снимком в этот
момент**, так что правка или удаление оригинала потом не изменят того, что увидит модератор.

**Со стороны модератора.** Жалобы на сообщения сервера приходят в его же
*Настройки сервера → Reports*. Всё остальное, включая личные переписки, достаётся владельцу
пространства в админ-консоли, раздел **Reports**.

<p align="center"><img src="images/13-admin-reports.png" alt="Очередь жалоб" width="900"></p>

В каждой строке — кто пожаловался, чьё сообщение, когда, причина и сам текст, каким он был.
Три действия и одна метка:

| | |
| --- | --- |
| **Hide** | Сообщение остаётся на месте надгробием *«сообщение удалено»*, так что удаление видят все, кто его видел |
| **Delete message** | Строка исчезает, и от неё нигде ничего не остаётся |
| **Reply and close** | Отправляет автору жалобы ваш ответ личным сообщением и **пересылает ему то сообщение, о котором идёт речь**, чтобы ответ не был абстракцией. Ничего не удаляется |
| *Статус* | `open` / `resolved` / `dismissed` — метка, которую модератор переключает как хочет |

Все три действия закрывают жалобу: она становится **closed**, и обратно её оттуда ничто не
возвращает. Так задумано — очередь, из которой разобранное может уплыть обратно в «открыто»,
никому не нужна. Выпадающий статус, наоборот, просто метка и меняется свободно — пока действие
не закроет жалобу окончательно.

## Админ-консоль

`/admin`, и только для того, кто держит инстанс. Она про пространство целиком — у серверов
внутри него свои настройки, описанные выше.

<p align="center"><img src="images/10-admin-dashboard.png" alt="Сводка админ-консоли" width="900"></p>

| Раздел | |
| --- | --- |
| **Dashboard** | Счётчики и состояние частей системы |
| **Server Logs** | Живой лог самого API |
| **Audit Log** | Кто, что, с чем и когда сделал |
| **Users** | Все аккаунты: роль **в пространстве**, бан, кик, персональные права, удаление |
| **Servers** | Все серверы пространства, их владельцы и размер |
| **Spaces** | Арендаторы, когда инстанс держит больше одного |
| **Roles** | Роли пространства и биты их прав |
| **Invites** | Коды приглашений на всё пространство |
| **Reports** | Очередь жалоб на всё, включая личные переписки |
| **Bug Reports** | То, что пользователи прислали божьей коровкой |
| **Server Settings** | Имя инстанса, приветствие, переключатели регистрации, потолок загрузки, бэкапы, политика 2FA |

Переключатели регистрации стоит понимать до того, как их трогать:

- **Registration open** — рубильник. Выключен — аккаунт не создать вообще никак.
- **Invite-only** — аккаунтам, в том числе созданным через провайдера, нужен код.
- **Email verification** — до появления аккаунта надо подтвердить код из 6 цифр. Требует
  настроенного SMTP; без него коды доходят только до серверного лога.

Приложение открывается на диалогах. **☰** выдвигает навигацию: рейл серверов сверху, а под ним
каналы или диалоги того, что выбрали. Свайп вправо откуда угодно в переписке открывает ту же
шторку, свайп влево по сообщению отвечает на него.

Всё, что есть в вебе, есть и здесь: альбомы и просмотрщик, ответы, пересылки, реакции, правки,
закрепления, жалобы, голосовые сообщения и файлы — файл скачивается на месте с кольцом прогресса
и открывается тем приложением, которое с ним работает, не выводя вас из переписки.

Голосовые каналы работают так же: нажать, разрешить микрофон — и панель над полем ввода держит
звонок, пока вы читаете дальше. Иконка с людьми открывает список участников; тап по аватару где
угодно открывает карточку человека — роль, с какого месяца он здесь, и действия: написать,
позвонить, добавить в друзья, заблокировать.

<p align="center">
  <img src="images/60-m-profile.png" alt="Карточка человека" width="230">
  <img src="images/59-m-settings.png" alt="Настройки" width="230">
</p>

В настройках лежат профиль, тема, пароль, чёрный список и фон для личных чатов.

Пуш-уведомления приходят, если у инстанса настроен APNs; разрешение приложение спрашивает при
первом запуске, и отказ стоит вам уведомлений и ничего больше.

**Чем отличается от веба**, и всё это намеренно:

- Нет входа через провайдера — только почта и пароль. Поэтому аккаунт, созданный через
  провайдера, и просят придумать пароль.
- Нет админ-консоли. Настройки сервера и очередь жалоб живут только в вебе.
- Демонстрация экрана — только в вебе.
- Нет `Обзора` — на сервер попадают по коду приглашения, через **+** в рейле шторки.

## Справочник

**Клавиатура (веб)**

| | |
| --- | --- |
| `⌘K` / `Ctrl-K` | Командная палитра |
| `Enter` / `Shift+Enter` | Отправить / перенести строку |
| `Esc` | Закрыть палитру или окно, отменить правку |
| `Ctrl/⌘+Shift+M` | Микрофон (в голосовом) |
| `Ctrl/⌘+Shift+D` | Оглохнуть (в голосовом) |
| `Ctrl/⌘+Shift+V` | Камера (в голосовом) |
| *ваша клавиша* | Push-to-talk, после назначения в Настройки → Voice & Audio |

**Ограничения**

| | |
| --- | --- |
| Загрузка | 100 МБ на файл |
| Картинки, отправленные как *Фото* | Пережимаются под коробку 1600 px, оригинал не хранится |
| Альбом | До 10 картинок в одном сообщении |
| Список диалогов | Ширина 240–560 px |

**Где что лежит**

| | |
| --- | --- |
| Свои настройки | Шестерёнка внизу сайдбара |
| Настройки одного сервера | Клик по названию сервера над списком каналов |
| Жалобы на один сервер | Настройки этого сервера → Reports |
| Всё остальное, на весь инстанс | `/admin` |
